# Booking NodeJS

-- Online Apartment Booking application --

Clients can post their aparments with booking prices
Regular users can browse , search and categorize aparments based on various filters such as: prices, avabile dates, locations... (MAIN Aspect?)
Through online automatized payment system - website acts as a middleman between two entities - automatizing payments using online payment B2B (U2U - User to User) services...

The end result is to solve posting aparments & finding them in an easy way, easing the process of booking for winter/summer seasons.
